# МойДискорд

Текстовые и голосовые каналы, демонстрация экрана — как в Discord, но **без серверов**:
компьютеры общаются напрямую — в локальной сети, через [Radmin VPN](https://www.radmin-vpn.com/)
или через интернет по коду приглашения (сеть на [iroh](https://github.com/n0-computer/iroh): QUIC,
пробивка NAT, всё зашифровано).

## Возможности

- **Текстовые каналы** — Markdown (`**жирный**`, `*курсив*`, `` `код` ``, блоки кода, ссылки),
  ответы, редактирование и удаление, реакции, упоминания `@имя` / `@все`, картинки и файлы
  до 25 МБ (вставка из буфера и перетаскивание), индикатор «печатает…», непрочитанные.
- **Голосовые каналы** — Opus 48 кГц напрямую между участниками, эхоподавление и шумоподавление
  WebRTC (можно без наушников), активация голосом с
  автоматической чувствительностью или режим рации (глобальная клавиша — работает в играх),
  выключение микрофона/звука, громкость каждого участника, звуки входа/выхода.
- **Демонстрация экрана** в голосовом канале — FFmpeg, захват DXGI, аппаратное кодирование
  NVENC (или x264), до 1440p60, звук компьютера через «Стерео микшер».
- **История без сервера** — у каждого участника свой журнал событий; когда вы снова в сети,
  пропущенные сообщения досинхронизируются от любого, кто онлайн.
- Темы (тёмная, пепельная, полночь, светлая, системная), акцентный цвет, масштаб текста.
- Выбор устройств ввода/вывода, проверка микрофона.
- Автозапуск с Windows, сворачивание в трей, запуск свёрнутым, уведомления Windows.
- **Горячие клавиши** — глобальные (работают в играх и не перехватывают клавиши у игры):
  микрофон `Ctrl+Shift+M`, звук `Ctrl+Shift+D`, рация, демонстрация, вход/выход из голосового
  канала, показать окно; можно назначить кнопки мыши 4/5 и одиночный модификатор.
  В окне: `Ctrl+K` — быстрый переход, `Alt+↑/↓` — каналы, `Ctrl+/` — все сочетания.
- Обновления из [релизов](https://github.com/Marsikcat/screen-share/releases): приложение само
  сообщает о новой версии, показывает, что изменилось, и обновляется в один клик.

## Установка

1. Скачайте **MoyDiscord-Setup-X.Y.Z.exe** из последнего
   [релиза](https://github.com/Marsikcat/screen-share/releases/latest) и запустите.
2. Права администратора не нужны: программа ставится в `%LOCALAPPDATA%\Programs\МойДискорд`,
   ярлыки появятся в «Пуске» и (по желанию) на рабочем столе.
3. При первом запуске Windows спросит доступ к сети — разрешите хотя бы для частных сетей.

Программа не подписана сертификатом, поэтому SmartScreen может показать «Windows защитила ваш
компьютер»: **Подробнее → Выполнить в любом случае**.

Обновления приложение предлагает само: скачивает новый установщик и ставит его в один клик.
Если друзья вас не видят: **Настройки → Сеть → «Открыть порты в брандмауэре»**.

## Как это работает

- Каждый участник — пара ключей Ed25519: публичный ключ служит ID, им подписано каждое сообщение.
- Соединения — QUIC через [iroh](https://github.com/n0-computer/iroh): в локальной сети и Radmin
  напрямую, через интернет — с пробивкой NAT, а если не вышло, через ретранслятор n0 (видит только
  шифрованные данные). В режиме «только локальная сеть» внешние сервисы не используются вообще.
- Комната — это секрет: открытые комнаты задаются названием (для своей сети), закрытые — только по
  коду приглашения. Участники доказывают знание секрета при каждом соединении. Код приглашения —
  около 80 символов: ключ друга, метка ретранслятора и комната, с контрольной суммой.
- История у каждого своя и досинхронизируется от тех, кто онлайн.

| Что | Порт | Протокол |
|---|---|---|
| Поиск участников в локальной сети | 8890 | UDP broadcast |
| Всё остальное (чат, голос, трансляция) | 8891 | UDP (QUIC) |

Данные хранятся в `%APPDATA%\MoyDiscord` (профиль, ключ, история, файлы) — папку с программой можно
переносить между компьютерами.

## Классическая демонстрация экрана

`classic.bat` открывает прежнее окно ScreenShare — трансляция по IP без каналов.
Из командной строки: `python screen_share.py send <ip>` / `python screen_share.py receive`.

## Требования

Windows 10/11, Python 3.10+ (ставится автоматически). Для NVENC — видеокарта NVIDIA.
Эхоподавления нет — в голосовых каналах лучше использовать наушники.

## Выпуск новой версии

1. Поднимите номер в `VERSION` и опишите изменения в `CHANGELOG.md` (раздел `## X.Y.Z`).
2. Сделайте коммит и `git push`.
3. `python release.py` — создаст релиз `vX.Y.Z` с архивом и описанием из `CHANGELOG.md`
   (нужен вход в GitHub CLI: `gh auth login`). У всех, у кого включена проверка обновлений,
   появится предложение обновиться.

История изменений — в [CHANGELOG.md](CHANGELOG.md).

## Из исходников (для разработки)

```
setup.bat     ставит Python-зависимости и FFmpeg в venv
run.bat       запускает приложение из исходников
classic.bat   старое окно ScreenShare
```

## Сборка и выпуск версии

```
tools\build.bat          dist\MoyDiscord\ (exe) и dist\MoyDiscord-Setup-X.Y.Z.exe
python tools\release.py  релиз vX.Y.Z на GitHub с обоими файлами
```

Для установщика нужен Inno Setup 6 (`winget install JRSoftware.InnoSetup`), для релиза — GitHub CLI
(`gh auth login`). Перед выпуском поднимите номер в `VERSION`, опишите изменения в `CHANGELOG.md`
и отправьте коммит на GitHub.

## Что где лежит

```
app.py              запуск приложения
moydiscord/         ядро: сеть (iroh), голос, демонстрация экрана, хранилище, обновления
moydiscord/ui/      интерфейс на PySide6
screen_share.py     классическое окно ScreenShare
assets/             иконка приложения
packaging/          спецификация PyInstaller и сценарий установщика
tools/              сборка, выпуск релиза, генерация иконки
```
