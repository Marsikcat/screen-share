# МойДискорд

Текстовые и голосовые каналы, демонстрация экрана — как в Discord, но **без серверов**:
компьютеры находят друг друга сами в локальной сети или в сети [Radmin VPN](https://www.radmin-vpn.com/)
и общаются напрямую.

## Возможности

- **Текстовые каналы** — Markdown (`**жирный**`, `*курсив*`, `` `код` ``, блоки кода, ссылки),
  ответы, редактирование и удаление, реакции, упоминания `@имя` / `@все`, картинки и файлы
  до 25 МБ (вставка из буфера и перетаскивание), индикатор «печатает…», непрочитанные.
- **Голосовые каналы** — Opus 48 кГц напрямую между участниками, активация голосом с
  автоматической чувствительностью или режим рации (глобальная клавиша — работает в играх),
  выключение микрофона/звука, громкость каждого участника, звуки входа/выхода.
- **Демонстрация экрана** в голосовом канале — FFmpeg, захват DXGI, аппаратное кодирование
  NVENC (или x264), до 1440p60, звук компьютера через «Стерео микшер».
- **История без сервера** — у каждого участника свой журнал событий; когда вы снова в сети,
  пропущенные сообщения досинхронизируются от любого, кто онлайн.
- Темы (тёмная, пепельная, полночь, светлая, системная), акцентный цвет, масштаб текста.
- Выбор устройств ввода/вывода, проверка микрофона.
- Автозапуск с Windows, сворачивание в трей, запуск свёрнутым, уведомления Windows.
- **Горячие клавиши** — глобальные (работают в играх и не перехватывают клавиши у игры):
  микрофон `Ctrl+Shift+M`, звук `Ctrl+Shift+D`, рация, демонстрация, вход/выход из голосового
  канала, показать окно; можно назначить кнопки мыши 4/5 и одиночный модификатор.
  В окне: `Ctrl+K` — быстрый переход, `Alt+↑/↓` — каналы, `Ctrl+/` — все сочетания.
- Обновления из [релизов](https://github.com/Marsikcat/screen-share/releases): приложение само
  сообщает о новой версии, показывает, что изменилось, и обновляется в один клик.

## Установка

1. Скачайте архив `MoyDiscord-X.Y.Z.zip` из последнего
   [релиза](https://github.com/Marsikcat/screen-share/releases/latest) и распакуйте, например,
   в `C:\MoyDiscord`.
2. Запустите `setup.bat` — он поставит Python (если нужно), зависимости и FFmpeg.
3. Запускайте `run.bat` или ярлык `MoyDiscord` на рабочем столе.

При первом запуске Windows спросит доступ к сети — разрешите для частных сетей.
Если друзья вас не видят: **Настройки → Сеть → «Открыть порты в брандмауэре»**.

## Как это работает

| Что | Порт | Протокол |
|---|---|---|
| Обнаружение участников | 8890 | UDP broadcast |
| Чат, синхронизация, состояние | 8891 | TCP |
| Голос (Opus) | 8892 | UDP |
| Демонстрация экрана (MPEG-TS) | 8888 | UDP |

Участники с одинаковой **комнатой** (Настройки → Сеть) видят одни и те же каналы.
Если автоматический поиск не находит друга (другая подсеть), добавьте его IP вручную там же.

Данные хранятся в `%APPDATA%\MoyDiscord` (профиль, история, файлы) — папку с программой можно
переносить между компьютерами.

## Классическая демонстрация экрана

`classic.bat` открывает прежнее окно ScreenShare — трансляция по IP без каналов.
Из командной строки: `python screen_share.py send <ip>` / `python screen_share.py receive`.

## Требования

Windows 10/11, Python 3.10+ (ставится автоматически). Для NVENC — видеокарта NVIDIA.
Эхоподавления нет — в голосовых каналах лучше использовать наушники.

## Выпуск новой версии

1. Поднимите номер в `VERSION` и опишите изменения в `CHANGELOG.md` (раздел `## X.Y.Z`).
2. Сделайте коммит и `git push`.
3. `python release.py` — создаст релиз `vX.Y.Z` с архивом и описанием из `CHANGELOG.md`
   (нужен вход в GitHub CLI: `gh auth login`). У всех, у кого включена проверка обновлений,
   появится предложение обновиться.

История изменений — в [CHANGELOG.md](CHANGELOG.md).
